# JS REST API Client

A dynamic product store built with vanilla JavaScript (ES6+ modules).

## Features
- Async/await fetch from FakeStoreAPI
- Real-time search, category tabs and sorting (no page reloads)
- Cart saved in localStorage
- Error banner with retry and loading skeletons

## Files
- `api.js` - API calls
- `app.js` - DOM logic and state
- `index.html`, `style.css` - layout and styling
